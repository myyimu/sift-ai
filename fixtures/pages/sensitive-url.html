链接集合页

本页正文用于抬高可读字符数，使捕获可以成功，从而逐一验证链接清洗规则：带凭证参数的链接剔除参数后保留，指向敏感路径的链接剥离 href 属性，普通链接原样保留。

  • 带 token 的文档链接：token 参数必须被剔除，page 与 sort 保留。
  • 登录入口链接：目标 path 命中 deny 词干，href 必须被剥离。
  • 编码绕过链接：先解码再判定，必须命中 deny。
  • 普通链接：href 原样保留。
  • 脚本协议链接：scheme 不在白名单，href 必须被剥离。
  • 域名黑名单链接：host 命中 denylist，href 必须被剥离。

结束段落：链接文本本身不受影响，只有 href 属性按规则清洗。
